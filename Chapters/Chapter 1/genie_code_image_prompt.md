# Genie Code image prompt (Chapter 1)

The prompt exchange from "Example: Genie Code and Agent Specialization"
in Chapter 1, reproduced here so you can copy and run it yourself.

## The request we gave Genie Code

```
Create a prompt, suitable for CoPilot, to create a diagram showing the
differences between a self-directed agent and a directed agent
```

## Genie Code's response

```
Prompt for CoPilot:

Create a visual diagram comparing self-directed agents versus directed
agents. The diagram should include:

Self-Directed Agent characteristics:

* Autonomous decision-making and goal setting
* Proactive task planning and execution
* Iterates until objectives are fully completed
* Makes reasonable assumptions when information is incomplete
* Manages its own workflow and prioritization

Directed Agent characteristics:

* Follows explicit instructions step-by-step
* Waits for user confirmation between major actions
* Executes specific tasks as commanded
* Asks clarifying questions when uncertain
* Requires user guidance for workflow decisions

Visual format suggestions:

* Use a side-by-side comparison layout or a Venn diagram showing overlaps
* Include arrows showing workflow patterns (linear for directed,
  cyclical/adaptive for self-directed)
* Use distinct colors for each agent type
* Add icons representing key concepts (autonomy, decision trees, user
  interaction points)
* Include 2-3 concrete examples for each type

Make the diagram clear, professional, and suitable for explaining AI agent
architectures to both technical and non-technical audiences.
```
